# Miokr · 纯前端本地 CSV 数据可视化工具

> miokr.com ｜ 面向仿真工程师、CAE / 有限元、科研人员与数据分析者的轻量级可视化工具。
> **所有文件全程在浏览器本地处理，不上传任何服务器。**

Miokr 是一款零后端、零数据库、可直接双击打开使用的静态可视化工具站。基于 D3.js 与 Observable Plot（均为 ISC 开源协议）构建，支持从基础统计图到高级可视化的完整图表能力，导出结果可用于论文、工程报告与商业演示。

---

## ✨ 核心特性

- **本地处理 · 零上传**：CSV 仅在浏览器内解析运算，数据不出本机，无隐私收集、无后台存储。
- **图表全覆盖**：10 种图表类型，一键切换。
- **数据清洗与筛选**：缺失值处理 / 行去重 / 条件筛选 / 行排序，规则以清单形式管理，可随时增删。
- **自动列识别**：自动区分数值列 / 文本列，并智能识别经纬度列。
- **手动选列 · 实时刷新**：自由选择 X / Y / 分组等字段，图表即时更新。
- **高清导出**：一键导出 PNG / SVG；会员无水印、高清输出。
- **合规安全**：地图功能仅渲染经纬度散点，不含任何底图，规避测绘资质问题。
- **双击即用**：依赖库本地内置，示例数据内联，`file://` 直接打开即可运行。

## 🧹 数据清洗与筛选

面板位于工具页「数据源」与「图表类型」之间，全部在浏览器本地完成，可叠加多条规则：

| 规则 | 说明 |
| --- | --- |
| 缺失值处理 | **删除**含缺失值的行 / **填充均值**（仅数值列）/ **填充常数**（文本列可用），可按单列或全部列执行 |
| 行去重 | 按指定列或全部列比对，保留首次出现的行 |
| 条件筛选 | 范围（≥ / ≤，可只填一边）、包含、等于、不等于、大于、小于 |
| 行排序 | 任意列升序 / 降序；数值列按数值比较，文本列按中文排序，空值始终排在末尾 |

- **非破坏式规则管线**：所有规则以有序清单展示，可逐条删除或一键清空；任何改动都基于原始数据重新计算，原始数据永不被修改。
- **可追溯**：数据栏显示「原始 N 行 / 清洗后 M 行」，图表标题显示已应用规则数，每条规则标注「处理前 → 处理后」行数。
- **空结果保护**：清洗后无剩余数据时给出中文空态提示，并阻止导出。
- 内置示例数据 `clean_demo`（含缺失与重复的试验记录）可直接体验以上全部规则。

## 🚀 使用方式

### 方式一：直接打开（最简单）

双击仓库根目录的 `index.html` 即可在浏览器中运行，无需安装、无需联网、无需服务器。

### 方式二：本地静态服务器（推荐用于开发调试）

```bash
# Python
python -m http.server 8080

# 或 Node
npx serve .
```

然后访问 `http://localhost:8080`。

### 方式三：部署上线

本项目为纯静态站，可直接部署到任意静态托管：

- **GitHub Pages**：仓库 Settings → Pages → 选择 `main` 分支根目录即可。
- **任意 Web 服务器 / 对象存储 / CDN**：上传全部文件，保持目录结构不变。

## 🖱️ 工具页操作流程

1. 顶部「数据源」区：上传本地 CSV，或从下拉选择内置示例数据（共 7 组）。
2. 「数据清洗与筛选」区：按需添加缺失值处理 / 行去重 / 条件筛选 / 行排序规则，规则清单实时更新，可逐条删除。
3. 「图表类型」区：点击切换 10 种图表之一。
4. 「字段映射」区：为当前图表选择对应的数据列（切换图表类型会自动预选合适字段）。
5. 右侧图表区实时刷新，悬浮查看 tooltip。
6. 右上角「导出 SVG / 导出 PNG」下载图表。
